# chad-personal WordPress

- `wordpress-theme/chad-personal/` — custom theme. Zip this folder and upload via Appearance > Themes.
- `tools/import/` — essay import: `import-essays.php` reads `posts-wp.json` (Markdown sources in `md/`). Run with WP-CLI, e.g. `wp eval-file tools/import/import-essays.php`.

No secrets or wp-config in this repo.
